# crucible

MoE expert compression toolkit — prune, merge, and forge specialist models for
local inference.

See the [repository README](https://github.com/peonist-ai/crucible) for the full
documentation, results, and evaluation protocol.

Benchmarking lives in the separate `crucible-bench` package: compression
produces weights, measurement talks to an endpoint, and they share neither
imports nor a dependency tree.
